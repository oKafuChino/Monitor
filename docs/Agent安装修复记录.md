# Agent 安装修复记录

2026-10-02，根据 Linux 安装错误日志修复。

原因：原脚本为兼容 POSIX shell 给 `EUID` 赋值，但该变量在 Bash 中只读；默认下载固定指向项目 latest release，不检查发行版是否包含探针资产。镜像只能解决网络问题，不能补出不存在的资产。原脚本还会先卸载已有服务，再下载新二进制，导致下载失败时丢失已有安装。

修改：使用普通 `installer_uid`；通过 jq 严格解析 API，按平台资产筛选稳定版／Snapshot／指定 tag，排除 draft 和未完成上传；无资产时明确报错；下载成功前保留旧安装；使用临时文件与退出清理；常规日志不再回显命令参数中的 Token。发行工作流增加已有 release 的 `release_tag` 手动补传入口（main 源码、不覆盖资产），保留空输入只构建的行为。

验证：本地 Git Bash 语法检查及 5 项离线模拟测试通过（成功安装、Snapshot 提示、解析无结果、下载失败、非法 tag），未启动系统服务。Windows 环境没有 jq，真实 jq 过滤器测试本地跳过，已纳入 Linux CI 且 CI 不允许跳过。工作流 YAML 和 shell 步骤语法已检查，git diff --check 已通过。当前环境 GitHub API 访问失败，线上 release 内容未确认；没有执行 CI、上传资产、发布镜像或部署节点。

交付边界：修改仅在本地工作区。需要将修复推送到 main，并完成 Snapshot 或已有 release 的探针资产补传，然后重新执行安装命令。没有产物时，单纯修改安装 URL 无法让下载成功。
