## 迁移与回退约定

- 沿用 `ThemeConfiguration` 的 `default` 行；这是兼容存储，并非重新开放主题平台。
- 已有有效 default 值优先；缺失的受支持键从旧活动主题复制，再填充内置默认值。旧主题行与主题/插件历史文件不自动删除。
- 设置写入、`theme=default` 和 `_builtin_ui_migration_v1` 标记在同一事务内完成。`_builtin_ui_previous_theme_v1` 保留迁移前活动主题，便于回退判断。
- 重复迁移不覆盖已保存的新值。直接 SQL 改回旧 theme 也不会影响实际 UI 或静态资源来源。
- 损坏 JSON 原始行保留并记录日志，读取回退到内置默认值。损坏的 default 行在管理员修复/恢复前，PATCH 返回 409，防止隐式覆盖原始数据。
- 引导过滤 markets/terminal 步骤，保留 install/notifications，workbench 继续使用原键但语义变为文件管理。
- `/themes/default/komari-theme.json` 也不再公开：新前端直接打包声明文件，无需保留旧资源 API。
