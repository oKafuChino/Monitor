# 临时分享节点

管理员在「设置 → 站点 → 临时分享节点」选择一个可见节点，生成 1 天、1 周、1 个 UTC 日历月或永久链接。永久链接仍可撤销。完整链接只显示一次，刷新后仅保留掩码。新建链接不会撤销其他链接。每节点最多 20 条活跃分享，全站最多 1000 条；每链接最多 100 个有效会话。

## 启用

默认不启用分享监听。直接运行示例：

```sh
KOMARI_LISTEN=127.0.0.1:25774 \
KOMARI_SHARE_LISTEN=127.0.0.1:25775 \
./komari server
```

监听地址为启动配置，更改后重启。分享地址必须显式指定 host 和有效端口，主站和分享端口必须不同。

启动后在「设置 → 站点 → 临时分享节点 → 分享公开地址」填写 `https://share.example.com` 并保存。地址持久化在数据库的 `share_public_base_url`，保存后立即用于链接生成及分享端 Host/Origin 校验，无需重启。`KOMARI_SHARE_PUBLIC_BASE_URL` 环境变量及 `--share-public-base-url` 参数已移除；已有部署请将原值填写到后台。公开 URL 必须是不含路径、查询、凭证或 fragment 的 HTTPS origin；仅 localhost / loopback 允许 HTTP 开发模式。

地址留空时不允许创建链接，分享路由返回 404，但监听端口仍启动。更换域名需先准备 DNS/证书/反代并同步调整代理的 Host；旧域名会立即被拒绝。分享凭证本身仍有效，已有链接需要换成新 origin 再打开，浏览器在新域名重新获取会话。

Compose 默认保持原主站配置。分享功能通过可选文件开启，需要 Docker Compose 2.24.4+ 的 `!override` 支持：

```sh
docker compose -f compose.yaml -f compose.share.yaml up -d --build
```

此覆盖配置将两个端口映射到宿主机 loopback。启动后在后台保存分享公开地址。同宿主机代理连接这些地址；Docker 内的代理可完全不发布端口，直接访问容器网络。Agent 仍需能访问主站上报入口，请按部署拓扑保留受控入口。安装脚本不自动设置 DNS、修改防火墙或更改已有主站监听地址。

分享站必须使用独立域名。Cookie 按 host 隔离，端口不能隔离 Cookie。主站应只绑定 loopback/内网，或使用防火墙、VPN、IP allowlist 和代理访问控制。换端口不保证主站不可扫描；同 IP、DNS 历史、证书仍可能形成关联。

## Nginx 示例

```nginx
server {
    listen 443 ssl;
    server_name share.example.com;
    ssl_certificate /path/to/share/fullchain.pem;
    ssl_certificate_key /path/to/share/privkey.pem;
    # /s/<token> 是能力凭证，整个分享站禁记 URI。
    access_log off;
    error_log /dev/null;
    location / {
        proxy_set_header Host share.example.com;
        proxy_set_header X-Forwarded-Proto https;
        proxy_pass http://127.0.0.1:25775;
    }
}
```

应用默认不信任代理 IP 转发头；如需按访客 IP 限流，明确设置 `KOMARI_SHARE_TRUSTED_PROXY=127.0.0.1/32` 并由代理覆盖 `X-Forwarded-For`，不能直接透传不受信任的值。主站域名只代理主端口，并按需要设置独立访问控制。应用校验 Host 等于公开 origin 的 host；直接端口测试需提供该 Host。

## 协议与边界

`GET /s/<token>` 校验后设置 host-only、HttpOnly、Secure、SameSite=Lax 会话 Cookie，302 到 `/node`。HTTPS Cookie 名为 `__Host-monitor_share`，本地 HTTP 为 `monitor_share_dev`。会话最多 24 小时且不超过分享到期时间。会话凭证和分享凭证均只持久化哈希；原 token 不进入 HTML、持久化前端状态或应用访问日志。

分享端独立路由只有 `/s/:token`、`/node`、构建允许的 `/assets/:name`、`/api/share/rpc` 和 `/healthz`。健康检查返回空 204。未知路由不回退 SPA。静态资源仅允许独立构建中的 JS/CSS，不提供主站 chunk、source map、PWA、favicon 或自定义 HTML。

```json
{"jsonrpc":"2.0","id":1,"method":"share:getNode","params":{}}
{"jsonrpc":"2.0","id":2,"method":"share:getLatestStatus","params":{}}
{"jsonrpc":"2.0","id":3,"method":"share:queryMetrics","params":{"metric_keys":["cpu.usage","disk.io.read.rate","disk.io.write.rate"],"hours":24,"max_points":500}}
```

所有 RPC 使用同源 POST，携带已认证 Cookie。拒绝批量、未知字段、UUID/entity、tags 和所有主站方法。历史也可使用 RFC3339 `start`/`end`，不能与 `hours` 混用。服务端计算默认时间，历史最多最近 30 天、24 个内置指标、每序列 500 点，10 秒查询超时，并受原保留期限制。Ping 只返回该节点任务名称与分享内哈希 ID，不返回目标或 Clients。GPU 历史标签只提供本地 ID。

响应为 no-store、no-referrer、noindex，带 CSP。Recharts 图表定位依赖 inline styles，因此 style-src 允许 unsafe-inline；脚本仍只允许自身。限流为全局 6000 请求/分钟、IP 静态 180/分钟、IP 数据 120/分钟、IP 换票 20/分钟、token 换票 30/分钟、链接数据 300/分钟、链接历史查询 12/分钟，进程重启重置计数。代理如需更严格限制可进一步收紧。

每请求重新验证节点、撤销和到期。隐藏或删除同步撤销，恢复显示不会恢复旧链接；修改为隐藏时在同一事务内撤销。管理员 session/API key/Agent token 在分享端不提供身份。旧 temp_key 全站放行已删除，旧配置字段保留但启动时清空；数据库回滚到旧程序仍需自行评估旧版本安全性。

通过应用的 backup.zip 恢复流程恢复数据库后撤销全部分享并删除会话。直接覆盖数据库文件绕过恢复流程不能检测备份之后的撤销记录，须在对外开放前手动撤销全部分享。

前端 5 秒轮询，失效/网络错误清空资料和图表；后台恢复先清空再认证。已下载的数据无法收回。不要在代理、监控、analytics、聊天预览或审计系统记录原链接。
