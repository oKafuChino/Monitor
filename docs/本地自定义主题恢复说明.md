# 默认主题回退与本地自定义主题

## 当前范围

前台恢复 Liquid Kawaii 改版前的内置默认布局、导航、节点卡片、指标进度条和详情页；保留监控、磁盘 I/O、图表模板和已有接口修复。移除液态主题样式及欢迎区，不重做后台视觉。

入口为 **系统设置 → 外观**。支持列出已安装主题、上传本地 ZIP、替换同一 `short` 的主题、显式启用、单独配置、恢复默认与删除非活动主题。默认主题不能被上传覆盖或删除。替换活动主题会立即更新前台文件，安装其他主题不自动切换。

不提供主题市场、主题搜索、GitHub/URL 拉取、远程下载或在线更新。插件、终端、远程执行、文件管理与通知能力不恢复。旧 Liquid Kawaii 设计文档仅作为历史资料。

## 主题包

ZIP 根目录结构：

```text
komari-theme.json
dist/
  index.html
  assets/
    app.js
    app.css
```

清单示例：

```json
{
  "short": "my-theme",
  "name": { "zh-CN": "我的主题", "en": "My theme" },
  "version": "1.0.0",
  "configuration": {
    "type": "managed",
    "data": [
      { "key": "greeting", "type": "string", "name": "欢迎语", "default": "Hello" }
    ]
  }
}
```

- `short` 长度 1–64，以字母或数字开头，其余为字母、数字、下划线或短横线。保留 `default`（不区分大小写）与 Windows 设备名。清单 `short` 必须与安装目录一致。
- 包大小最多 64 MiB，解压后总计最多 256 MiB，单文件最多 32 MiB，清单最多 1 MiB，总条目最多 4096。
- 仅接收根清单与 `dist/`，拒绝目录穿越、绝对路径、反斜杠、设备路径、符号链接、重复/大小写冲突文件。不运行安装脚本。
- 在 `data/theme/` 内暂存、完整校验，再发布主题文件；失败的包不能替换已有完整主题。沿用旧主题配置，不覆盖 `default` 行。
- `url`、`author`、`preview` 仅为元数据，服务端不会访问其中的远程地址。

## 资源与兼容

主题公开资源为 `/themes/<short>/dist/...`，清单为 `/themes/<short>/komari-theme.json`。不公开主题根目录其他文件。

服务端为自定义入口插入主题资源 base，并将 HTML 中脚本、媒体与样式引用映射到主题命名空间。推荐 Vite 等工具使用 `base: './'` 构建，使模块、懒加载块与 CSS 资源随入口解析。路由和 API 应使用绝对站内路径，例如 `/instance/<uuid>`、`/api/public`；不要依赖相对 `api/public`。

兼容旧主题的根路径静态资源：仅在内置资源未命中时，尝试活动主题的同名资源。内置文件始终优先。不要依赖覆盖 `/assets/` 中的内置同名文件；复杂运行时硬编码绝对路径的主题可能需要重建为相对 base。不会自动改写 JS/CSS 内的任意字符串。

`/admin`、`/install`、`/database-recovery` 以及受限启动监听器始终返回内置页面。受限监听器不开放主题资源。主题资源响应禁止缓存，并将 Service Worker 最大 scope 限制到主题自己的 `dist/`；内置根 Service Worker 不被主题覆盖。独立分享站构建、路由与 CSP 不变。

自定义主题是同源可执行前端代码，并非沙箱：可信主题可以用当前浏览器登录身份访问接口。安装/启用前需要在界面确认来源可信；安装完成、启用、删除、写配置均沿用敏感操作二次验证。不要安装不可信主题。

## 配置与回退

- `/api/public` 返回实际有效 `theme` 和对应 `theme_settings`。主题缺失、清单无效或入口缺失时返回内置主题；不抹除原选择和旧配置，方便修复。
- 内置/后台设置继续走原 `GET/PATCH /api/admin/ui/settings`，保留 schema 白名单与事务合并。
- 自定义主题各自使用 `ThemeConfiguration.short` 行，`managed` 清单生成表单；其他配置类型提供 JSON 对象编辑，不在后台执行主题自带的 HTML 配置页面或跳转页面。
- 自定义配置是前台公开数据，不能放密钥。保留 `false`、`0` 和空字符串，拒绝 `_komari_` 管理内部键；未加密、不承诺作为秘密存储。
- 恢复默认只切换活动主题；保留已安装主题及其配置。删除需先切换离开目标主题，随后移除其文件和配置。
- 启用/恢复后刷新前台页面生效，后台界面不随主题更换。

管理员接口（均需管理员认证；变更接口有既有 CSRF/二次验证约束）：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/admin/theme/list` | `{active, themes}`，含内置默认主题 |
| POST | `/api/admin/theme/set` | JSON `{short}`，启用或恢复 `default` |
| POST | `/api/admin/theme/delete` | JSON `{short}`，删除非活动自定义主题 |
| GET | `/api/admin/theme/settings?theme=<short>` | 读取自定义配置与清单默认值 |
| PUT | `/api/admin/theme/settings?theme=<short>` | 用 JSON 对象替换该主题配置 |
| POST | `/api/admin/upload/{init,chunk,merge,cancel}` | 复用分片上传，`purpose: "theme"` |

通用设置接口禁止直接选任意磁盘主题，需使用专用启用接口。市场、下载、更新路径保持 404。
